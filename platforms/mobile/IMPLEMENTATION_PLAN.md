## 5. Known Gotchas & Solutions

### 1. FFI Bridge Complexity

**Issue:** flutter_rust_bridge v2 has learning curve

**Solution:**
- Start with simple functions (unit conversion)
- Use `#[frb(sync)]` for pure functions
- Return JSON strings for complex structs initially
- Test FFI boundary thoroughly

### 2. Rust Build Times

**Issue:** Initial compilation can take 5-10 minutes

**Solution:**
- Use debug builds during development (`cargo build` without `--release`)
- Incremental compilation helps on subsequent builds
- Consider `sccache` for distributed caching

### 3. iOS Simulator vs Device

**Issue:** Different Rust targets needed

**Solution:**
- Build script handles all targets automatically
- Use `lipo` to create universal simulator binary
- Test on both simulator and physical device

### 4. SVG Rendering

**Issue:** SVG from Rust must render in Flutter

**Solution:**
- Use `flutter_svg` package (handles most SVG features)
- Test with actual generated SVGs early
- Fallback: Export as PNG if compatibility issues

### 5. State Management

**Issue:** Many interdependent fields (aspect ratio lock, validation)

**Solution:**
- Keep business logic in Rust (single source of truth)
- Flutter just displays and mutates Rust state
- Use Provider for simple change notifications
