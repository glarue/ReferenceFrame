# Planning Docs (Historical)

These are historical planning documents, kept for reference. Each has a status header noting how much of the plan was actually implemented; they are not maintained and may not reflect the current codebase.

Active (exception): `WOOD_GRAIN_PLAN.md`, the species wood-grain rendering plan, maintained until the feature ships.

Parked (not implemented): `cut-pieces-view-spec.md` and `cut-pieces-implementation-guide.md`, with illustrative mockups in `mockups/`.

The HTML mockups (`mockups/cut-pieces-example*.html` here, and the shipped corner-detail mockups in `../archive/mockups/`) are illustrative only and are not kept in sync with the app. Obsolete PyScript-era and superseded docs live in `../archive/`.
