# Legacy Code

This directory contains archived/deprecated code that is no longer actively maintained.

## pyscript/

The original PyScript proof-of-concept version of ReferenceFrame. This was a client-side web application using Python compiled to WebAssembly via Pyodide.

**Status**: Archived (2026-01-03)
**Reason**: Replaced by the Rust/WASM implementation which offers better performance and cross-platform support.

The PyScript version is fully functional but no longer maintained. For the active web application, see `platforms/web/`.
